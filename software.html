SW-Crawl

A one-page tribute to the opening crawl from Star Wars, built to see how far plain CSS animation could be pushed. The text climbs away into a starfield over a space backdrop, and the story scrolling past is one I wrote myself. There is no framework and no JavaScript in it — only HTML and a stylesheet — and I kept a journal in the repository of what broke along the way and how I fixed it.

MathCanvas

An interactive maths and physics explorer. It plots constant, linear, quadratic, sine, cosine and tangent curves; takes a small set of observations and returns the mean, median, standard deviation, variance and range with a bar chart beside them; and simulates projectile motion from a launch angle, speed and mass. Pick a mode, change an input, and the graph redraws. The whole interface is Streamlit, NumPy and Matplotlib — there is not a single HTML tag in it.

  • Streamlit
  • NumPy
  • Matplotlib

Culinary Guide

A small recipe site with a page for each dish: garlic butter pasta, a caprese salad, a stir-fry with tofu and a veggie quesadilla. Each page carries a progress bar showing how hard the recipe is to cook, and a dialog box at the end holding a bonus link. It is almost entirely HTML, with just enough JavaScript to make the dialog work and no stylesheet at all.

Hangman

The word-guessing game, written in Python and played in the terminal. The computer picks a word at random, you guess one letter at a time, and every letter that is not in the word costs you an attempt. It is a single file that needs nothing beyond Python itself, and I packaged it with PyInstaller so it can be run on Windows without installing anything first.
